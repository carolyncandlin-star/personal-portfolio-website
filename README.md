<!-- #Personal Portfolio Website -->

A professional, modern and responsive personal portfolio website developed using HTML5, CSS3 and JavaScript. This portfolio showcases my education, technical skills, projects and experience as a final-year B.Tech Artificial Intelligence and Machine Learning student.

About the Project

The Personal Portfolio Website was developed as part of my Web Development Internship task at Avenir Technosys LLP.

The main objective is to create a professional online presence where visitors can learn about my background, explore my projects and connect with me.

Features

- Professional Homepage: Introduction, animated typing effect and call-to-action buttons.
- About Me: Personal introduction, academic background and current status.
- Skills Section: Technical skills displayed with percentage-based progress bars.
- Projects Showcase: Project cards with screenshots, descriptions and technology tags.
- Education and Experience: Organized timeline displaying academic and professional experience.
- Contact Form: Input validation for name, email and message fields.
- Responsive Navigation: Desktop navigation and mobile hamburger menu.
- Dark and Light Themes: Theme switching functionality.
- Animations: Typing effect, floating elements and scroll reveal animations.
- Back to Top: Button for easy navigation.

How to Run the Project

1. Clone or download this repository.
2. Extract the downloaded project if necessary.
3. Open the project folder in Visual Studio Code.
4. Open "index.html" in your browser.
5. Alternatively, use the Live Server extension in VS Code for a better development experience.

No additional frameworks or installations are required.
